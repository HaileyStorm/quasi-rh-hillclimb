# Proposals (Track B)

Put one file per structural idea in this folder, named `YYYY-MM-DD-short-name.md`. Each file should cover:

1. **Change:** which input of the budget changes. Give the lemma and the line numbers in `build/paper.tex`.
2. **Needed statement:** the exact new estimate you need, with all exponents written out.
3. **Payoff:** the σ₀ it would give. Give the `whatif.py` command, or attach your own modified budget script.
4. **Evidence:** why you think the statement is true, plus any partial proof.
5. **What breaks:** other lemmas or inequalities that the change affects.

A proposal only becomes a result once the needed statement is proved. When it is, change its row in `../results.md` to `proved`.
