## Context (important for reading the verdicts)
The whole range is the proof of Lemma `lem:plain` (statement at 12531-12579). In it, **M = m+q is a local induction width, not the geometric M = 5/6**. Likewise **ℓ is a local pool-prime density length (ℓ = 0 or ℓ_* = σ/3, lines 13450, 13457, 13524, 13562)**, not the geometric ℓ; **h is a Poisson row/frequency variable** (and at 12870 a height order); **b is a plain length (12952) or an exponent order (12870)**; **d is a log-norm (13210) or a removed slot length (14259)**; L = M/4 is local. Slot lengths are the z_i, constrained only by z_i ≤ η (mesh) and the affine region (3.9): A + (6κ−1)z ≤ M. None of the geometric constants 7/8, 1/6, 13/16, 1/8, 17/48, 23/48, 3/16, 11/16 or 1/48 appears in the range. The only 5/6 is the slope 5M/6, which comes from sixth-power row counting (eq. exceptional-row-count) and has nothing to do with the geometry. Δ and β* > 7/8 are never used. The only parameter that enters is κ ∈ [3/4,1], and the only zero-free input is β* ≤ (1+κ)/2.

I checked these identities symbolically (sympy) and they hold: (2.12), (2.13) M' = M+J−g−g_2+t_2, (2.15)-(2.16), (3.14), and the J ≥ 0 simplification of F_1. ## 2. PROBLEM / NEEDS-EDIT items
1. **NEEDS-EDIT (commentary only, lines 12581-12585, adjacent to the range):** "The application to the 7/8 bound sets κ=2β_*−1, so its zero-free hypothesis in this lemma holds by equality. We retain this dynamic value rather than replace it by the value 5/6…". Under the new scheme the lemma is invoked with κ = 3/4. Its hypothesis "β* ≤ (1+κ)/2 = 7/8" (line 12565, used at 12834 and 12897) holds by the preprint's main theorem, not by equality. This is a wording change only. The lemma's proof never needs κ = 2β*−1 or κ > 3/4.
2. **Note (not a problem):** every κ-sensitive inequality in the range (12932, 12949, 14259-14273, 14827) needs only κ ∈ [3/4,1], and each is tight or valid at κ = 3/4. In particular 6κ−1 ≥ 7/2 and z ≤ 2M/9 hold with equality.
3. **Note on logic:** the zero-free input is used only as an upper bound on real parts (contour at Re s = 7/8 + e with e > 0). So it holds for any β* ≤ 7/8, including σ₀ < β* ≤ 7/8. It does rely on the preprint's theorem β* ≤ 7/8 being taken as established, and that theorem was proved with this same lemma at dynamic κ. That is not circular for the follow-up.

No PROBLEM items: there is no use of Δ, β* > 7/8, "≤ 1/6", or the geometric ℓ, h, b, l_x, l_y or M in this range.

## 3. Verdict
Yes: lines 12602-14985 go through unchanged at the new geometry with κ = 3/4. The proof is fully general in the local width M, the slot lengths z_i ≤ η and κ ∈ [3/4,1]. The only edit needed is the application remark at 12581-12585 just before the range.
